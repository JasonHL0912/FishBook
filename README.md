# 渔船航期记账与经营分析工具

一个面向渔船主的单文件记账工具，记录每个航期的采购开销、卖鱼收益、员工工资与预支，并提供可视化图表与经营分析。

## 功能

- 航期管理（启航/返航日期、自动计算天数与月数）
- 采购与船上开销（分类记录）
- 卖鱼收益（按鱼种/单价/重量自动算金额）
- 员工工资（按月薪 × 航期月数结算）
- 预支工资（单独立账）
- 可视化卡片图表（收支对比、成本构成、鱼种占比）
- 经营分析（内置规则 + 可选接入大模型 API）
- 数据导出/导入备份

## 技术说明

纯前端单文件应用，无后端。数据保存在浏览器 localStorage 中，离线可用。

## 部署

本仓库通过 Netlify 自动部署：推送到 `main` 分支即自动发布。

- 构建命令：留空
- 发布目录：`/`

## 更新发布流程

修改 `index.html` 后，在 `fishbook` 目录运行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\publish.ps1 -Message "本次更新说明"
```

脚本会通过 GitHub CLI 把文件推送到仓库的 `main` 分支，Netlify 随即自动重新部署（约 10 秒）。手机刷新站点即可看到新版本。

前提：已安装 GitHub CLI 并完成 `gh auth login`。
